# Security Policy

## Reporting a vulnerability

Please open a private security advisory on this repository (Security → Advisories → Report a vulnerability).
Do not file public issues for security problems.

## Threat model and controls

| Threat                                                    | Control                                                                                                                                                                                                                                                                      | Where                                                | Verified by                                            |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| API key exposure                                          | Key read only from server env (`GEMINI_API_KEY`, never `VITE_`-prefixed); the browser only calls our own `/api/plan`                                                                                                                                                         | `server/gemini.ts`                                   | Code review; no key in the client bundle               |
| Cross-site use of the API (CSRF-style abuse, quota theft) | Browser requests whose `Origin` names another host are rejected with 403                                                                                                                                                                                                     | `server/handler.ts`                                  | `tests/handler.test.ts`, smoke test                    |
| Prompt injection fabricating results                      | User text wrapped in delimiters and labelled untrusted; numeric tools take **no numbers from the model** (they read server-side state); action ids filtered against tool output                                                                                              | `server/agent.ts`                                    | `tests/agent.test.ts`                                  |
| Malformed or malicious tool arguments                     | Every tool call validated with Zod (enums, ranges, lengths); errors returned to the model, never thrown                                                                                                                                                                      | `server/agent.ts`, `shared/schemas.ts`               | `tests/agent.test.ts`, `tests/tools.test.ts`           |
| Harmful generated text                                    | Gemini safety settings block harassment, hate, sexual and dangerous content at medium and above; model text is length-bounded and rendered as escaped text                                                                                                                   | `server/agent.ts`                                    | `tests/agent.test.ts`                                  |
| Runaway cost / denial of wallet                           | Per-IP rate limit (8/min), response cache for repeats, 6-turn agent budget, 45 s abort, 1,200-char input cap, 4 KB body cap (read stops early)                                                                                                                               | `server/handler.ts`, `server/node.ts`                | `tests/handler.test.ts`, `tests/node.test.ts`          |
| Information leakage                                       | Generic 500 messages; internal errors logged server-side only, correlated by `X-Request-Id`; `Cache-Control: no-store` on API responses; cache keys are SHA-256 hashes, not user text                                                                                        | `server/handler.ts`, `server/cache.ts`               | `tests/handler.test.ts`, `tests/cache.test.ts`         |
| XSS / clickjacking / sniffing                             | Strict CSP with no `unsafe-inline` or `unsafe-eval` (`default-src 'self'`, `frame-ancestors 'none'`), HSTS preload, `nosniff`, `X-Frame-Options: DENY`, Referrer-Policy, restrictive Permissions-Policy, COOP; React escapes all rendered text, no `dangerouslySetInnerHTML` | `vercel.json` (also applied by the container server) | `tests/static.test.ts`, smoke test, live browser audit |
| Path traversal (container)                                | Static paths are decoded, null bytes rejected and resolved inside the web root only                                                                                                                                                                                          | `server/static.ts`                                   | `tests/static.test.ts` (encoded and null-byte attacks) |
| Container compromise blast radius                         | Runs as the unprivileged `node` user; production dependencies only; health check                                                                                                                                                                                             | `Dockerfile`                                         | CI container job                                       |
| Vulnerable dependencies                                   | `npm audit --audit-level=high` gate in CI; Dependabot for npm and GitHub Actions; patched transitive `@grpc/grpc-js` pinned via `overrides`; minimal runtime deps                                                                                                            | `.github/`                                           | CI                                                     |

## Third-party data

Firebase Analytics and Performance Monitoring receive only aggregate fields (plan source, latency, counts, rating band) and standard page-performance traces, never the text a user types. Firebase starts only after the first user interaction. The CSP allows only the specific Google endpoints Firebase needs. Firebase web config is public by design; it is supplied by environment variable so each deployment is configurable and no key-shaped strings live in source.

## Known limitations

- The rate limiter and cache are in-memory per instance. For multi-region production use a shared store (for example Firestore or Memorystore).
- No user accounts or personal data are stored. Descriptions are sent to the Gemini API for processing only.
